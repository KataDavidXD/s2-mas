# Scientific reproduction entry points

[Training, model loading and paired metrics](../../reproduction/training/README.md) provide the generic scientific interfaces. Input preparation uses explicit task/question IDs, candidate IDs and authored input values.

The [paper reproduction entry](../../paper/README.md) provides aggregate sources and plotting commands for the one-shot and stateful shock applications.

The [paper source data](../../paper/source_data/) contain the approved reported aggregates. Applicable model and data access conditions accompany the relevant release; code availability does not grant rights to separate inputs or model weights.
