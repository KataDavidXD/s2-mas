# Wikidata structured context vocabulary

The package contains 38 non-person entities, 66 P150/P31 relations and two property labels retrieved on 19 October 2026. It supplies bilingual concept names and parent/type relations for assigned synthetic contexts. Entity frequencies are not population weights.

`cc0_vocab.json`, `cc0_entities.csv` and `cc0_relations.csv` use **CC0-1.0**. They contain structured entity/property facts, not Wikipedia articles, biographies, images or text from Wikidata discussion/help pages. Their CC0 reuse, including commercial reuse, remains independent of persona, scenario and model terms.
