# Attribution and actual inputs

**Real-survey aggregate reference:** disposable income CNY41,314 and consumption CNY28,227 are annual per-capita expectation-scale targets used by the independent synthetic generator. These aggregate scales do not supply household observations or attribute bundles. The real-survey reference is described generically; this package does not distribute its underlying data.

**Assigned synthetic construction:** the independent RNG generator supplies new random financial proportions and contract parameters. Household size and non-flow stocks are authored settings. Scaling uses the aggregate expectation scales; no respondent rows or attribute bundles are copied.

**Wikidata structured knowledge:** 38 entities and 66 relations provide labels, administrative types and parent relationships for assigned contexts. These assets remain CC0. They do not determine income, debt, behavior or population frequencies.

The previously authored eight-task designs retain their CC BY 4.0 attribution, and the reused/new Python code remains Apache-2.0. No model training or model inference is part of this data construction. This new version is a separate public companion resource; it was not used in the existing model checkpoints or the paper's completed 2M/12M applications.
